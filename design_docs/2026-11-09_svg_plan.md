# SVG Output Plan

**Date:** 2026-11-09
**Status:** plan (2026-11-09). Nothing ruled; the open forks are listed under Decisions.

**Scope.** Add `emblem::svg`, a `Sink` that turns a decoded IconVG graphic into
deterministic, self-contained SVG text, so derived faces and authored symbols
reach the web without script or a rasterizer: merelyllc.com, release-log pages
served through the HTTP compatibility layer (mere
`design_docs/mere_docs/implementation_strategy/2026-11-03_release_log_plan.md`),
docs, and SVG favicons. It lowers paths, fills, gradients, the ViewBox, the
level-of-detail arm chosen at emission, and optionally palette slots as CSS
variables. Out of scope: stroking, text, SVG-to-IconVG import, rasterizing, and
any styling beyond what the bytes say.

Companion: mere `design_docs/mere_docs/implementation_strategy/2026-11-09_iconography_plan.md`
(new faces and uses; this plan is its web export).

Receipts go to `design_docs/archive_docs/receipts/2026-11-09_svg_plan_receipts.md`.

## What exists

- `Sink` receives only `move_to`, `line_to`, `quad_to`, `cube_to`, `close` and
  `fill(&Paint)` (`src/sink.rs:117-139`), in absolute coordinates with the
  graphic's transform applied (`sink.rs:112-114`). Arcs never reach it: ellipse
  ops are lowered to cubics in the VM (`src/vm/geometry.rs:107-117`).
- `Paint` is `Flat(Rgba)` or `Gradient { kind, spread, stops, matrix }`
  (`sink.rs:76-91`); colours are premultiplied (`src/color.rs:1-10`); `Spread`
  is `None`, `Pad`, `Reflect` or `Repeat` (`sink.rs:19-28`); `matrix` is the
  effective gradient matrix, graphic space to gradient space (`sink.rs:88`).
- The VM resolves palette slots before the sink sees them (`src/vm.rs:380`,
  `418`; blends in `Registers::color`, `color.rs:156`). A sink cannot tell a
  slot from a literal.
- `Metadata { view_box, suggested_palette }` (`src/meta.rs:62`), `ViewBox`
  (`meta.rs:26`), `Host { features, height }` with arm selection by height, a
  half-open range test (`vm.rs:47-56`, `227-231`), `execute` (`vm.rs:72`).
- Fills are non-zero only (`sink.rs:134-137`); the VM closes the open subpath
  before each fill (`vm.rs:450-458`).
- Doctrine: deterministic encoding, no rasterizer, zero dependencies,
  `forbid(unsafe_code)` (`README.md:38-43`, `src/lib.rs:101`). The crate already
  uses `Vec`, so an alloc-only module adds no requirement.
- File ceiling 600 lines (`line-ceiling.toml`); `vm.rs` is 484, `sink.rs` 255.
- Worked lowering precedent: pictograph's vello bridge (mere
  `crates/canvas/pictograph/src/vello.rs`): `straight_color` (291), the linear
  brush basis (305), the radial inverse (137), spread mapping (146), the
  `Spread::None` clip strip or disc (172-203).
- First consumer: `merelyllc.com/assets/favicon.svg` is hand-authored text and a
  rect, linked from `html/*.html` as `image/svg+xml`.

## Design

Signatures are illustrative.

```rust
// feature "svg", no dependencies
pub struct SvgOptions { pub id_prefix: IdPrefix, pub theme: Theme }
pub enum Theme { Snapshot, CssVars { prefix: IdPrefix } } // default Snapshot
pub fn to_svg(file: &[u8], palette: &Palette, host: Host, o: &SvgOptions)
    -> Result<String, SvgError>;
pub struct SvgSink { .. } // impl Sink; new(view_box, &SvgOptions); finish() -> String
```

**Where it lives.** Inside emblem behind a default-off `svg` feature. It is a
`Sink` like `Recorder`: a lossless projection of the segment and paint sequence,
with no rules. The README's "format-pure" stays true with one added clause: the
module never adds, merges, reorders or drops anything the bytes say. The
gradient mathematics, the hard part, then sits beside the VM, the spec examples
and the conformance tests, and a site build or favicon generator needs emblem
alone. Pictograph is the wrong home (it pulls vello and peniko); a separate
crate costs a publish and a version lock for a few hundred lines with no
dependency of its own.

**Mapping.**
- Paths: absolute `M L Q C Z`, one `<path>` per `fill`, in call order, nothing
  merged; every command letter written. No arc commands exist to emit.
- `fill-rule="nonzero"` on every path, explicit.
- ViewBox to `viewBox="min_x min_y w h"`; the outer `<svg>` clips to it by
  default. Only `xmlns` is emitted; width and height only when the caller sets
  them.
- Flat colour: straight sRGB `#rrggbb` plus `fill-opacity` when alpha is below
  255. Unpremultiply with the bridge's rounding (`(c*255 + a/2)/a`, capped);
  alpha 0 emits `#000000` with opacity 0. Low-alpha straight values are
  approximate because 8-bit premultiplied colour is quantized; documented.
- Linear gradient: colour depends on `t = a*x + b*y + c` (the matrix's first
  row). Emit `x1,y1 = (-a*c/n, -b*c/n)` and `x2,y2 = x1,y1 + (a/n, b/n)` with
  `n = a² + b²`, `gradientUnits="userSpaceOnUse"`, no `gradientTransform`.
  `n == 0` or a non-finite value is an `SvgError`.
- Radial gradient: `cx=0 cy=0 r=1`, user-space units,
  `gradientTransform="matrix(...)"` of the inverse effective matrix in SVG
  column order. A singular matrix is an `SvgError`.
- Spread: `Pad`, `Reflect`, `Repeat` to `spreadMethod`. `None` (transparent
  outside [0,1]) has no SVG equivalent: emulate it as the bridge does, a
  `<clipPath>` strip (linear) or disc (radial) in brush space, applied with
  `clip-path`, gradient spread `pad`. A faint antialiased seam is accepted and
  documented.
- Stops: `<stop offset stop-color stop-opacity>`. IconVG interpolates
  premultiplied, SVG straight. Opaque spans are exact; a span whose stops differ
  in alpha gets a fixed eight intermediate stops computed by premultiplied
  interpolation. Documented as an approximation.

**Determinism.** The same bytes, palette, host and options always give the same
text, so SVG can be content-addressed like the `.ivg`. Rust's `{}` for `f32` is
shortest-roundtrip but not a stability promise across toolchains, so numbers go
through a private fixed-point formatter: scale in `f64`, round half away from
zero, trim trailing zeros, normalize `-0`. Four fractional digits for
coordinates, offsets and opacities; six for gradient points and matrices.
Non-finite is an error. Only IEEE `+ - * /` (no libm, no `mul_add`). Gradient
ids are a counter in fill order (`{prefix}g0`, `g1`, …); element and attribute
order is fixed.

**Theming.** `Theme::CssVars` recovers palette slots without changing the VM by
a probe differential: execute twice, with the caller's palette `P` and with a
probe palette `P'` of 64 distinct opaque colours where `P'[i] != P[i]`. A paint
colour is slot `i` iff pass one gives `P[i]` and pass two gives `P'[i]`. A
literal cannot differ between passes; blends and alpha-scaled slots differ
without matching and stay literal. Slot paints become
`style="fill:var(--emblem-slot-3,#rrggbb)"` (and `stop-color` likewise); `style`
rather than a presentation attribute because `var()` is not reliable there.
Opacity is baked from `P`. Variables reach inline SVG only; in `<img>` and
favicon use the fallback hex is the snapshot. An inline `style` fails under a
strict CSP; documented.

**Level of detail.** The arm is chosen at emission by `Host.height` (the VM
already does this), one text per target height. Emitting all arms with CSS
conditions does not work: `@media` tests the viewport, container queries on SVG
internals are uneven, and `<img>` ignores host CSS.

**Security.** Emitted elements: `svg, defs, path, linearGradient,
radialGradient, stop, clipPath, rect, circle`. Every value is a formatted
number, a `#rrggbb`, a fixed keyword or a counter id. No `<script>`, `<style>`,
`<use>`, `<image>`, `href`, event attribute or external reference. Metadata
carries no text, so nothing user-controlled is emitted. The only caller strings,
`id_prefix` and the variable prefix, go through a newtype accepting
`[A-Za-z0-9_-]{1,32}`.

## Phases

- **V1. Core.** `src/svg.rs` (sink and `to_svg`), `src/svg/fmt.rs` (number
  formatting), the feature and a `cfg(feature = "svg")` re-export. Done when: a
  test decodes the spec's 36-byte action/info icon (`tests/vm.rs:19`) and
  compares against a committed expected SVG string verbatim; a second test covers
  a flat graphic with alpha; the formatter has table tests (`-0`, 0.5, 1/3, large
  values, non-finite errors); two runs give identical bytes; the crate tests,
  clippy and docs pass with and without the feature through the build wrapper;
  every new file is under the ceiling.
- **V2. Gradients.** `src/svg/paint.rs`: linear, radial, all four spreads,
  alpha-stop subdivision. Done when: a committed expected string per kind and
  spread passes; singular matrices and non-finite stops error; `Spread::None`
  output contains a `clipPath` and the other spreads do not.
- **V3. Theming and options.** Probe differential, `Theme::CssVars`, validated
  prefixes. Done when: a graphic filling from custom slots emits
  `var(--emblem-slot-N, …)` whose fallback equals the snapshot colour; a literal
  and a blended fill stay literal; changing the palette changes snapshot output
  but not the structure of `CssVars` output; a rejected prefix is tested. The
  browser behaviour of `var()` in `style` on stops is checked once by hand and
  stated in Findings.
- **V4. Adoption docs.** A README section and module docs naming exactly where
  SVG differs (premultiplied interpolation, the `None` clip, quantization,
  unthemable alpha). Done when: the README matches the tests.

A raster comparison against the vello bridge is optional and manual (it needs
both rasterizers); if run, its outcome is one sentence in Findings.

## Decisions

None ruled. Open forks, recommended first:

- **Placement:** `svg` feature in emblem; a separate `emblem-svg` crate;
  pictograph.
- **Slot theming:** probe differential in `to_svg`, no VM change; a
  default-method `Sink::fill_from` carrying a slot origin from the VM; no theming.
- **Alpha-stop spans:** eight premultiplied intermediate stops; straight stops
  with a documented divergence; a caller-chosen count.
- **`Spread::None`:** clip strip or disc; refuse with an error; approximate with
  `pad`.
- **Number precision:** four digits for coordinates and six for gradients;
  three and six; caller-configurable (weakens content addressing across
  callers).

## Findings

- 2026-11-09: arcs reach the `Sink` only as `cube_to` (`src/vm/geometry.rs:107-117`);
  no arc output is needed. The `Sink` carries no slot origin; palette slots are
  resolved at `vm.rs:380` and `418`.
- 2026-11-09: pictograph's `vello.rs` already covers unpremultiplying, the
  one-row linear basis, the radial inverse, all four spreads and the `None` clip,
  so this lowering has a worked precedent, and the SVG linear case reduces to two
  points.
- 2026-11-09: `merelyllc.com/assets/favicon.svg` exists, hand-authored with
  `<text>`; a generated IconVG face or mark would replace it.
